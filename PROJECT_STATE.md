## Goal

One local-first roleplay workbench for authoring, organizing, validating and testing character cards, lorebooks and presets, without silent data loss between formats. Plan goal: a creator never loses a card, never silently breaks it, and can find and fix problems without paying for AI. Details: `docs/PRODUCT_VISION.md`.

## Stack and structure

- React 19, Vite 6, TypeScript, Tailwind 4, Zustand 5, Dexie (IndexedDB), Zod, `gpt-tokenizer`, vitest. Deployed on Vercel as a PWA.
- `src/`: `components`, `constants`, `core` (pure logic: `chatMarkup`, `coverAsset`, `pasteImport`), `db`, `hooks`, `io` (formats), `routing` (hash routes), `schemas`, `services` (AI providers), `store` (slices), `types`, `utils`.
- `docs/`: `AI_WORKFLOW.md` (rules and roles), `DECISIONS.md` (numbered decisions, infrastructure facts), `BUGS.md` (verified bugs and risks), `tasks/` (open task cards), `ROADMAP.md` (priority plan and the v1.0.0 cutline), `ARCHITECTURE.md`, `AUTOMATION.md`, `research/` (verified findings, no decisions), `PLATFORM_SUPPORT.md`, `TESTING_STRATEGY.md`, `UI_UX_REDESIGN_SPEC.md`, `PRODUCT_VISION.md`.
- Scripts: `npm run lint && npm test && npm run build`. 45 test files in `test/`; the executor's last local run (PR #41 description): lint 0 errors and 45 warnings (warnings do not fail CI), 303 tests passing, build ok. UI audit: `scripts/ui-audit.py`. Smoke test: `scripts/smoke.py` (Python Playwright, run by hand against `vite preview`, usage in its docstring; not in CI; 19 checks: load, import, open, edit-save with reload, 7 screens, JSON export, backup export, backup restore in a fresh browser context, restore again with an unchanged card count, desktop load/import/open, no runtime errors; the executor's run at PR #41 passed all 19, as reported in the PR description, not re-run by Claude).
